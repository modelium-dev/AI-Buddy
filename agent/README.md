# Переносимый пакет агента

Агент «Путь стажёра» переносится в корпоративную ИИ-платформу без изменения оркестратора:

* промпты RCTF — `../prompts/`;
* инструменты MCP — `tools.json` (те же имена, что у `mock-corp`: `wiki.*`, `tracker.*`, `git.*`, `access.*`, `absence.*`, `org.*`);
* флаги — `flags.json` (A/B: `guide_mode_default`);
* ИИ-крон — `cron.example.yaml` (синхронизация задач и утренняя сводка).

Чтобы подключить настоящие сервисы, укажите `MCP_URL` реального MCP-сервера с теми же инструментами.
