# Остальные промпты (RCTF)

## Роутер — `app/assistant/router.py` (`ROUTER_SYSTEM`)
**ROLE:** роутер ассистента стажёра. **CONTEXT:** последние 6 реплик, этап, задача. **TASK:** классифицировать сообщение.
**FORMAT:** JSON `{"route","topic_group","topic","needs_person","confidence"}`. Невалидный JSON — одна повторная попытка, затем `lookup`.
Действия (заявки, практика) запускаются только детерминированными правилами, не догадкой модели.

## «Навести» — `app/assistant/templates.py` (`GUIDES`)
Не давай готового решения. Формат: (1) один уточняющий вопрос или шаг проверки, (2) подсказка, где искать, с источником.
Если это второй наводящий ответ подряд, следующий — прямой ответ и человек.

## Брокер знакомств — `app/assistant/people.py` (`broker_message`)
**ROLE:** помощник по профессиональной коммуникации. **CONTEXT:** стажёр обращается к {person.name} ({person.role}) по теме «{topic}».
**TASK:** сформулируй обращение, показывающее, что стажёр уже проверил документы.
**FORMAT:** JSON `{"message":"2–3 предложения","questions":[..],"duration":"20 минут"}`. Тон уважительный, без извинений за беспокойство.

## Журнал — `app/services/journal.py` (`suggest`, `draft_text`)
Вход: только выбранные чаты. Выход: `[{text, chat_title}]`, 1–5 записей, первое лицо, без выдуманных фактов.
